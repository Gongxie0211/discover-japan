# 🇯🇵 Discover Japan

A comprehensive travel guide for Myanmar visitors to Japan covering all 47 prefectures.

## Features

- **47 Prefectures** — Complete coverage from Hokkaido to Okinawa
- **94 Tourist Spots** — 2 iconic locations per prefecture
- **94 Local Foods** — Traditional specialties in Japanese
- **Wikipedia Photos** — Auto-loaded images for every location
- **Google Maps Integration** — Direct navigation links for all spots
- **Furigana Support** — Kanji pronunciation for non-Japanese readers
- **Bilingual Content** — English descriptions + Myanmar/Japanese

## Access

🌐 **Live Demo:** https://gongxie0211.github.io/discover-japan/

## Content Structure

- **Regions:** Hokkaido, Tohoku, Kanto, Chubu, Kinki, Chugoku, Shikoku, Kyushu & Okinawa
- **Spot Details:** Location descriptions in English (Pref 1-20) and Myanmar (Pref 21-47)
- **Food Guide:** All local specialties in Japanese with English translations

## Technical Details

- Pure HTML5 with responsive design
- Wikipedia REST API for dynamic photo loading
- CSS dark theme with gold accents
- Zero external dependencies beyond Wikipedia API
