## 確認ポイント

テスト後、以下を確認してください：

1. **タグ** — 冒頭に `#キーストーン #XOP` 等が5〜8個出るか
2. **Wikiリンク** — `[[キーストーン]]` `[[吉岡さん]]` 等が正しく入っているか
3. **セクション構成** — 午前/午後/顧客対応/タスク/懸念/明日の予定 が揃っているか
4. **フィラー除去** — テスト③で「えーと」「あの」「まあ」が消えているか
5. **憶測なし** — メモにない情報が補完されていないか
6. **該当なし** — 内容がないセクションに「該当なし」が入っているか
7. **タスク引き継ぎ（テスト④）** — 前日タスクの完了/継続が正しく判定されるか
   - キーストーン見積もり → [x] 完了になるか
   - 入札案件の判断 → [x] 完了（見送り）になるか
   - MTG資料 → [ ] 継続または要確認になるか
