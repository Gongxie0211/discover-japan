# プロトケア XOP — 競合分析レポート

> 作成日：2026-06-07  
> 目的：XOPセールスにおける競合との差別化ポイントを整理し、営業トーク・Webコピーに活用する  
> 調査対象：日本市場の石材・コンクリート保護コーティング主要製品

---

## 概要：競合マップ

XOPが戦う市場は大きく3つのカテゴリーに分かれる。

| カテゴリー | 代表製品 | XOPとの距離 |
|---|---|---|
| **無機系浸透型（強化・防水）** | ウォーターセラミック（アクアテック） | ★★★ 最も近い競合 |
| **フッ素+シリコーン系浸透型（防汚）** | アリストン（ミヤキ）・AD-COAT | ★★ 中程度 |
| **グローバル建材大手** | シーカ・ジャパン（Sika） | ★★ 中程度 |
| **膜型（塗料・フッ素塗料）** | 一般フッ素系外壁塗料全般 | ★ 間接競合（根本的に違う） |

XOPは「高価格帯・大型商業施設・文化財・高級建築」にフォーカス。  
**住宅用の一般外壁塗装市場とは勝負しない。**

## 競合製品 詳細

### 1. ウォーターセラミック（アクアテック社）— 最重要競合

**メーカー**：株式会社アクアテック（日本）  
**成分**：シリカ系（無機質）  
**タイプ**：浸透型・表層結晶化  
**実績**：**国宝・姫路城** 改修工事（漆喰保護）、NETIS（国土交通省新技術情報提供システム）登録済み  
**流通**：建設業者・左官業者向け、建材商社経由

#### 強み
- 無機系シリカで表層を結晶化・固結 → 耐久性向上
- 防水・防カビ・塩害防止
- 姫路城実績（20年以上の経年確認）
- NETIS登録 → 公共工事採用実績あり
- 文化財・行政案件に強いブランド

#### 弱点（XOPの攻め口）

| 項目 | ウォーターセラミック | プロトケア XOP |
|---|---|---|
| **主な機能** | 防水・表層強化（防汚は補助） | **防水＋撥油＋防汚＋UV対策** の4機能 |
| **UV（紫外線）対策** | なし | **フッ素結合が250nmでないと切れない → 太陽光では分解不可** |
| **撥油性** | 記述なし | **撥油で油汚れ・排ガスを弾く** |
| **雨による自浄** | なし | **撥水＋勾配で雨が汚れを洗い流す** |
| **ターゲット** | 文化財・公共工事 | **商業施設・高級建築（GINZA SIX等）** |
| **施工者** | 左官・専門業者 | **クラックス社が直接対応** |

**トーク素材**：
> 「ウォーターセラミックは文化財での実績がある優れた製品ですが、主目的は防水・表層強化です。XOPはそれに加えて、撥油・防汚・UV対策まで一体で提供します。高級商業施設の外壁は排ガスや油煙の汚れとの戦いでもある。雨で自浄する撥水・撥油の組み合わせは、ウォーターセラミックにはない機能です。」

### 2. アリストン（株式会社ミヤキ）

**メーカー**：株式会社ミヤキ（日本）  
**成分**：**フッ素 + シリコーンの混合**  
**タイプ**：浸透型・防汚剤  
**対象**：御影石・大理石・テラゾー・磁器タイル・レンガ  
**流通**：石材業者・メンテナンス業者・ECサイト

#### 強み
- 撥水・撥油・防汚 の3機能
- 石材の風合いを変えない浸透型
- 石材向け専門製品として認知度高い
- 施工・入手が比較的容易

#### 弱点（XOPの攻め口）

| 項目 | アリストン | プロトケア XOP |
|---|---|---|
| **成分** | **フッ素+シリコーン混合** | 純フッ素系（より高耐久） |
| **PFAS問題** | **フッ素系→EU規制対象方向、環境・健康リスク懸念** | ※XOP成分要確認（PFAS非該当の場合は強い差別化点） |
| **UV耐久性** | シリコーン部分が紫外線で劣化する可能性 | **フッ素結合は地表紫外線で分解されない** |
| **大規模施工** | 主にDIY・石材清掃業者向け | **建設・施工プロ向け、大型物件対応** |
| **実績** | 建材業界一般 | **GINZA SIX・六本木ヒルズ** |

**トーク素材**：
> 「アリストンはフッ素+シリコーン混合系です。シリコーン部分は紫外線で劣化するため、長期耐久性がフッ素単体より劣ります。また、フッ素系塗料はEUでPFAS規制の対象となる方向で、中長期的なリスクも考慮が必要です。XOPの技術的優位性と施工実績をあわせてご判断ください。」

> ※PFAS問題の言及は慎重に。XOPのフッ素がPFAS非該当であることをキーストンに確認してから使う。

### 3. AD-COAT（株式会社アクト・ビズ）

**メーカー**：株式会社アクト・ビズ（日本）  
**成分**：浸透性吸水防止剤（フッ素/シリコーン系と推定）  
**タイプ**：浸透型・吸水防止  
**実績**：文化財修復実績あり  
**対象**：石材・コンクリート・タイル・レンガ

#### 強み
- 文化財修復専門企業が提供
- 浸透型で風合いを変えない
- 御影石・大理石・御影石ホワイト専用ラインアップ

#### 弱点（XOPの攻め口）

| 項目 | AD-COAT | プロトケア XOP |
|---|---|---|
| **主機能** | 吸水防止（防水） | **防水＋撥油＋防汚＋UV対策** |
| **UV耐久** | 記述なし | **フッ素結合が太陽光で分解されない** |
| **施工者** | 文化財専門業者 | **大型商業施設・高級建築向け** |
| **第三者試験** | 文化財向け仕様 | **（一財）建材試験センター** 試験取得済み |

### 4. シーカ・ジャパン（Sika Group）

**メーカー**：Sika AG（スイス系グローバル建材メーカー）、日本法人あり  
**製品**：コンクリート・石材向け浸透性吸水防止材等  
**関連実績**：GINZA SIX（外装・防水関係）  
**流通**：ゼネコン・大手建設会社向け

#### 強み
- グローバルブランドの信頼性
- ゼネコンルートへの浸透度が高い
- 製品ラインナップが幅広い（接着・防水・補修・保護）

#### 弱点（XOPの攻め口）

| 項目 | シーカ | プロトケア XOP |
|---|---|---|
| **専門性** | 総合建材メーカー（石材専用コーティングが主力ではない） | **石材・コンクリート保護に特化** |
| **撥油・防汚** | 製品により異なる（石材専用防汚ラインは薄い） | **撥水＋撥油＋防汚が一体** |
| **日本サポート** | 外資系（日本語サポート・対応速度） | **日本製・クラックスが直接対応** |
| **施工柔軟性** | 大型プロジェクト中心 | **規模問わず対応可** |

### 5. 膜型フッ素塗料（一般外壁塗装）— 根本的に違う

**代表例**：ルミフロン系フッ素塗料、AGCコーテック等  
**タイプ**：造膜型（表面に塗膜を形成）

#### 根本的な問題（XOPの核心差別化）

> 「膜を張る塗料は一見守っているように見えます。でも紫外線・熱膨張・凍結融解で膜が割れると、水がその隙間に入り込み、膜の下に閉じ込められます。内部の水分がカビ・苔・凍害を引き起こし、素材を内側から壊す。これが**再塗装が必要な根本原因**です。XOPは膜を張りません。石の孔に入り込み、内部で結晶化して一体化する。だから剥がれず、素材は呼吸し続けます。」

| 項目 | 膜型フッ素塗料 | プロトケア XOP |
|---|---|---|
| 工法 | 造膜（表面に塗膜形成） | **浸透（内部に結晶化）** |
| 剥がれ・割れ | **紫外線・温度変化で発生** | 起きない（塗膜なし） |
| 内部劣化 | **膜下に水が閉じ込まり内部から腐食** | 透湿性あり・素材が呼吸できる |
| メンテ周期 | **5〜10年で再塗装** | 壁面10年以上・メンテ費70%以上削減 |
| 素材の見た目 | 光沢・艶が付く（質感が変わる） | **自然な風合いそのまま** |

## XOP 差別化ポジション マトリクス

```
  機能の多さ（防水+撥油+防汚+UV）
         多い
              │
              │        ★ プロトケア XOP
              │         （無機浸透・4機能・長耐久）
              │
無機浸透型────┼────────有機/膜型
              │
              │  ウォーターセラミック    アリストン
              │ （防水・強化中心）      （防汚中心・混合系）
              │
         少ない
         膜型塗料（剥がれ・再塗装サイクル）
```

**XOPのポジション**：「無機浸透 × 4機能（防水・撥油・防汚・UV）× 長耐久」の領域はXOPが独占

## XOPが勝てる勝負どころ

### 1. 高級商業施設・オフィスビル
- 外観の維持が事業価値に直結
- 定期的な外壁清掃・足場コストが重い
- XOP: GINZA SIX・六本木ヒルズの実績で信頼性訴求

### 2. 新築高級建築（引き渡し時施工）
- 引き渡し後の劣化リスクを最初からゼロに
- デベロッパー・設計事務所への初期提案が勝ちパターン
- 「竣工時に施工しておけば10年以上守られる」

### 3. 石材・御影石・大理石を使う建築
- 石材は一度汚れが染みると落ちにくい（エフロ・油汚れ・排ガス）
- 竣工直後の施工が最も効果的

### 4. 文化財・歴史的建造物（ウォーターセラミックとの差別化）
- ウォーターセラミックは防水・強化特化
- XOP: 防水＋撥油＋防汚＋UV → 4機能で攻める
- ただし文化財向けは「成分への保守的姿勢」があるため実績先行で

## セールストーク（競合比較版）

### 「ウォーターセラミックと何が違いますか？」

> 「ウォーターセラミックは無機系で防水・表層強化に優れた製品です。姫路城での実績もあります。ただ、主機能は防水・強化です。XOPはそこに**撥油・防汚・UV耐久**が加わる。特に都市部の建築では、排ガスや油煙が大敵です。XOPは撥油性で油汚れを弾き、雨が降るたびに自浄する——ウォーターセラミックにはないポイントです。」

### 「他の石材保護剤（アリストン等）と何が違いますか？」

> 「フッ素とシリコーンの混合系は多くあります。ただ、シリコーン部分は紫外線で徐々に劣化します。XOPは純フッ素系で、フッ素の炭素結合を切るには波長250nmの紫外線が必要ですが、地表に届く太陽光は280nm以上。**つまり太陽光ではXOPは分解できない**。これが、10年以上持つ科学的な根拠です。」

### 「なぜ一般塗料より高いのですか？」

> 「一般塗料は5〜10年で剥がれて再塗装が必要です。足場の仮設・撤去だけで数百万円。それが何度も繰り返される。XOPの初期費用を高く感じるかもしれませんが、**10年以上塗り替えが不要**になるため、生涯トータルコストでは大幅に安くなります。しかも、足場を何度も立てる工事リスクや営業停止の機会損失も消えます。」

## 注意事項（営業時）

- ウォーターセラミック・アリストンを「悪い製品」と言わない → 適材適所で正直に話す
- PFAS問題の言及は「XOP自体がPFAS非該当である」ことをキーストン確認後に使用
- フッ素系の優位性は「250nm/280nm」の科学的説明とセットで使う（単なる主張でなく根拠）
- ウォーターセラミックは姫路城実績（文化財）、XOPはGINZA SIX（商業施設）→ ターゲット帯が異なることを念頭に
