## Label Design Requirements — UAE Compliance

| Requirement | Specification |
|-------------|---------------|
| Languages | English AND Arabic — both mandatory, equal prominence |
| Arabic text direction | Right-to-left. Arabic text must not be compressed or truncated |
| Minimum font size | 8pt for body text; 6pt absolute minimum for secondary information |
| Net content units | Metric (L, mL) required |
| Country of origin | "Made in Japan / صنع في اليابان" — mandatory on primary label |
| Barcode | EAN-13 or GS1-128; minimum size per GS1 specification |
| Label adhesion | Permanent adhesive. Label must not be removable without obvious damage to container |
| Print durability | Must remain legible after typical storage and transport conditions |
